#+title: Building UIs In Nest

Nest draws user interfaces by re-declaring them every frame. Widgets hold no
state of their own; the application owns its state and describes what the window
should contain right now. Positions and sizes come from a constraint solver, so
a declaration states relationships, not pixels.

Every portion of an interface is a ~widget~: a named routine that declares its
children, owns the state it needs, and emits its own events. A parent either
handles a child's event or emits one of its own in its place, so an interface
grows as a tree of small widgets rather than one state type and one event
enumeration.

The library API is documented in the generated reference (~nimble docs~). Layout
constraints are covered in [[file:layout.org][layout.org]]. Every built-in
widget is shown in the gallery application, ~apps/gallery/gallery.nim~
(~nimble gallery~).

* A Complete Application

A counter: its own state type, its own event type, one widget, one line to run
it.

#+begin_src nim
import nest

type
  Counter = object
    count: int

  CounterEvent = enum
    Incremented
    Decremented

proc update(model: var Counter, event: CounterEvent) =
  case event
  of Incremented: inc model.count
  of Decremented: dec model.count

widget counter(model: Counter) emits CounterEvent:
  ui.panel(ui.id("root"), cfg(padding = 16, gap = 12, alignItems = AlignCenter,
      justifyContent = JustifyCenter)):
    ui.label(ui.id("title"), "Counter", width = fit(), height = fit())
    ui.row(ui.id("controls"), cfg(width = fit(), height = fit(), gap = 8,
        alignItems = AlignCenter)):
      if ui.button(ui.id("dec"), "-", width = fixed(32), height = fit()):
        emit Decremented
      ui.label(ui.id("count"), $model.count, width = fixed(80), height = fit())
      if ui.button(ui.id("inc"), "+", width = fixed(32), height = fit()):
        emit Incremented

when isMainModule:
  runApp(AppConfig.init(width = 320, height = 160, title = "Counter"),
      Counter(), update, counter)
#+end_src

~runApp~ opens the window and runs the frame loop: it holds the model, calls the
root widget once per frame, and applies the events it emitted with ~update~.

* Widgets

~widget name(params): body~ declares a portion of an interface. It expands to a
routine that takes the ~UI~ as its first parameter and runs the body inside
~ui.scope("name")~.

#+begin_src nim
import nest

type Counter = object
  count: int

widget counterLabel(model: Counter):
  ui.label(ui.id("count"), $model.count, width = fit(), height = fit())

# The same declaration written by hand:
proc counterLabelByHand(ui: var UI, model: Counter) =
  ui.scope("counterLabelByHand"):
    ui.label(ui.id("count"), $model.count, width = fit(), height = fit())
#+end_src

The two declarations above are equivalent. The body is ordinary Nim, every call
keeps its ~ui.~ prefix, and turning a widget into a procedure or back is a change
to the header only. No type is declared, and nothing in the body has to move.

** Ids Are Scoped By The Widget

Because the body runs inside ~ui.scope("name")~, two widgets can both use
~ui.id("row")~ without meeting.

#+begin_src nim
import nest

widget header(title: string):
  ui.row(ui.id("row"), cfg(width = fill(), height = fit(), gap = 8)):
    ui.label(ui.id("text"), title, width = fill(), height = fit())

widget footer(text: string):
  # `ui.id("row")` here is a different id from the one in `header`.
  ui.row(ui.id("row"), cfg(width = fill(), height = fit(), gap = 8)):
    ui.label(ui.id("text"), text, width = fill(), height = fit())

widget page():
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 6)):
    ui.header("Title")
    ui.footer("Status")
#+end_src

The scope covers the widget's name, not its arguments, so declaring the same
widget twice in one frame still needs a scope at the call site.

#+begin_src nim
import nest

widget pane(title: string):
  ui.panel(ui.id("root"), cfg(width = fill(), height = fill(), padding = 8)):
    ui.label(ui.id("title"), title, width = fill(), height = fit())

widget splitView():
  ui.row(ui.id("root"), cfg(width = fill(), height = fill(), gap = 8)):
    ui.scope("left"):
      ui.pane("Left")
    ui.scope("right"):
      ui.pane("Right")
#+end_src

Reaching a widget's id from outside means entering its scope, which is how a
caller finds a widget it did not declare itself.

#+begin_src nim
import nest

widget searchBox(state: LineInputState):
  ui.lineInput(ui.id("input"), state, width = fill(), height = fixed(30))

proc focusSearch(ui: var UI) =
  ui.scope("searchBox"):
    ui.focus(ui.id("input"))
#+end_src

** When To Write A Plain Procedure

~widget~ adds a ~ui~ parameter and an id scope. Write a plain procedure when
neither is wanted: for code that computes rather than declares, and for a helper
that must share the caller's id scope.

#+begin_src nim
import nest

type Task = object
  title: string
  done: bool

# Computes; declares nothing.
proc summary(tasks: seq[Task]): string =
  var done = 0
  for task in tasks:
    if task.done:
      inc done
  $done & " of " & $tasks.len & " done"

# Declares, but deliberately shares the caller's scope, so the ids it builds
# belong to whichever widget called it.
proc rowLabel(ui: var UI, key, text: string) =
  ui.label(ui.id(key, "label"), text, width = fill(), height = fit())

widget taskList(tasks: seq[Task]):
  ui.column(ui.id("root"), cfg(padding = 8, gap = 4)):
    ui.label(ui.id("summary"), tasks.summary, width = fill(), height = fit())
    for task in tasks:
      ui.rowLabel(task.title, task.title)
#+end_src

* The Frame

~ui.layout~ runs its body twice.

| Pass   | Purpose                     | ~ui.inEventPhase~ | ~ui.inLayoutPhase~ |
|--------+-----------------------------+-------------------+--------------------|
| event  | dispatch last frame's input | true              | false              |
| layout | build the widget tree       | false             | true               |

Widget calls behave differently in each pass. ~ui.button~ returns whether it was
clicked during the event pass and builds a button during the layout pass.
Declaration-only calls such as ~ui.label~ do nothing during the event pass.

#+begin_src nim
import nest

widget passProbe(log: var seq[string]):
  if ui.inEventPhase:
    log.add "event pass"
  else:
    log.add "layout pass"
  ui.label(ui.id("hello"), "hello", width = fit(), height = fit())
#+end_src

Three rules follow from the double pass:

1. State changes belong in the event pass. Code that runs in both passes would
   apply a change twice.
2. Declarations must not depend on anything the layout pass changes, because the
   event pass has already run with the previous values.
3. Events are emitted during the event pass. Consume them where they are
   returned, or accumulate them with ~add~; assigning them to a variable that
   outlives the call loses them, because the layout pass runs the widget again
   and returns nothing.

A local whose name matches one of the ~ui.~ routines shadows it: a variable
called ~events~ breaks ~ui.events~, and a loop variable called ~row~ breaks
~ui.row~. Name an event queue ~emitted~, and a loop index ~rowIndex~.

~ui.events:~ marks a block as event-pass only.

#+begin_src nim
import nest

widget quitHint(quitRequested: var bool):
  ui.events:
    if ui.keyPressed("Escape"):
      quitRequested = true

  ui.label(ui.id("hint"), "Press Escape to quit", width = fit(), height = fit())
#+end_src

Interaction is recorded when a frame updates its widgets, and observed on the
next frame's event pass. A press therefore becomes a click one frame later; Nest
requests that frame itself, so no polling is needed.

#+begin_example
frame 1 no input   : count=0 drawn=[-,0,+]
frame 2 press on + : count=0 drawn=[-,0,+]
frame 3 held       : count=1 drawn=[-,1,+]
frame 4 release    : count=1 drawn=[-,1,+]
#+end_example

Frame 2 records the press. Frame 3 observes the click, applies ~Incremented~,
and draws ~1~ in that same frame.

* Events Between Widgets

A widget declares its own event type with ~emits~ and reports one with ~emit~.
The events it emitted are its return value, so its caller sees exactly what
happened inside it and nothing else.

#+begin_src nim
import nest

type
  ToolbarEvent = enum
    NewPressed
    OpenPressed
    SavePressed

widget toolbar(modified: bool) emits ToolbarEvent:
  ui.row(ui.id("root"), cfg(width = fill(), height = fit(), gap = 6,
      padding = 6)):
    if ui.button(ui.id("new"), "New", width = fit(), height = fit()):
      emit NewPressed
    if ui.button(ui.id("open"), "Open", width = fit(), height = fit()):
      emit OpenPressed
    if ui.button(ui.id("save"), "Save" & (if modified: " *" else: ""),
        width = fit(), height = fit()):
      emit SavePressed
#+end_src

** Handling A Child's Events

A parent reads the events where the call returns them.

#+begin_src nim
import nest

type
  ToolbarEvent = enum
    NewPressed
    SavePressed

  Document = object
    text: string
    modified: bool

widget toolbar(modified: bool) emits ToolbarEvent:
  ui.row(ui.id("root"), cfg(width = fill(), height = fit(), gap = 6)):
    if ui.button(ui.id("new"), "New", width = fit(), height = fit()):
      emit NewPressed
    if ui.button(ui.id("save"), "Save", width = fit(), height = fit()):
      emit SavePressed

widget editorPane(model: var Document):
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 6)):
    for event in ui.toolbar(model.modified):
      case event
      of NewPressed:
        model.text = ""
        model.modified = false
      of SavePressed:
        model.modified = false
    ui.label(ui.id("text"), model.text, width = fill(), height = fill())
#+end_src

** Raising An Event Further Up

A parent that cannot answer a child's event emits one of its own in its place.
The child's type stays private to the child; each level speaks its own
vocabulary.

#+begin_src nim
import nest

type
  ToolbarEvent = enum
    NewPressed
    SavePressed

  PaneEvent = enum
    SaveRequested
    TitleChanged

widget toolbar() emits ToolbarEvent:
  ui.row(ui.id("root"), cfg(width = fill(), height = fit(), gap = 6)):
    if ui.button(ui.id("new"), "New", width = fit(), height = fit()):
      emit NewPressed
    if ui.button(ui.id("save"), "Save", width = fit(), height = fit()):
      emit SavePressed

widget pane(title: var string) emits PaneEvent:
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 6)):
    for event in ui.toolbar():
      case event
      of NewPressed:
        # Handled here: the shell above never hears about it.
        title = "untitled"
        emit TitleChanged
      of SavePressed:
        # Raised: saving is not this widget's business.
        emit SaveRequested
    ui.label(ui.id("title"), title, width = fill(), height = fit())

widget shell(title: var string, log: var seq[string]) emits PaneEvent:
  ui.panel(ui.id("root"), cfg(width = fill(), height = fill(), padding = 8)):
    for event in ui.pane(title):
      case event
      of SaveRequested:
        log.add "writing " & title
      of TitleChanged:
        # Not this level's business either: pass it on.
        emit TitleChanged
#+end_src

** Events With Payloads

An enumeration is enough while events carry nothing. An object variant carries
what the parent needs, most often the identity of the row that produced it.

#+begin_src nim
import nest

type
  Task = object
    id: int
    title: string
    done: bool

  RowEventKind = enum
    Toggled
    Removed
    Renamed

  RowEvent = object
    id: int
    case kind: RowEventKind
    of Renamed:
      title: string
    else:
      discard

widget taskRow(task: Task) emits RowEvent:
  ui.row(ui.id("root"), cfg(width = fill(), height = fit(), gap = 8,
      alignItems = AlignCenter)):
    ui.checkbox(ui.id("done"), task.title, task.done, width = fill(),
        height = fit())
    if ui.clicked(ui.id("done")):
      emit RowEvent(id: task.id, kind: Toggled)
    if ui.button(ui.id("rename"), "Rename", width = fit(), height = fit()):
      emit RowEvent(id: task.id, kind: Renamed, title: task.title & " (copy)")
    if ui.button(ui.id("remove"), "x", width = fixed(24), height = fit()):
      emit RowEvent(id: task.id, kind: Removed)
#+end_src

** A List Of Children

Each row is scoped by its own identity, so the rows keep their widgets apart,
and the parent handles the events of all of them in one loop.

#+begin_src nim
import std/sequtils

import nest

type
  Task = object
    id: int
    title: string
    done: bool

  RowEvent = object
    id: int
    removed: bool

  TaskList = object
    tasks: seq[Task]

widget taskRow(task: Task) emits RowEvent:
  ui.row(ui.id("root"), cfg(width = fill(), height = fit(), gap = 8)):
    ui.checkbox(ui.id("done"), task.title, task.done, width = fill(),
        height = fit())
    if ui.clicked(ui.id("done")):
      emit RowEvent(id: task.id, removed: false)
    if ui.button(ui.id("remove"), "x", width = fixed(24), height = fit()):
      emit RowEvent(id: task.id, removed: true)

widget taskList(model: var TaskList):
  ui.column(ui.id("root"), cfg(width = fill(), height = fit(), gap = 4,
      padding = 8)):
    var emitted: seq[RowEvent]
    for task in model.tasks:
      # One scope per row, keyed by the task's own id.
      ui.scope(task.id):
        emitted.add ui.taskRow(task)

    # The list is only edited after every row has been declared.
    for event in emitted:
      if event.removed:
        model.tasks.keepItIf(it.id != event.id)
      else:
        for task in model.tasks.mitems:
          if task.id == event.id:
            task.done = not task.done
#+end_src

Collecting the rows' events first and editing afterwards keeps the sequence being
iterated from changing underneath the loop.

** Siblings

A parent that owns two children is the place where they meet: it turns one
child's event into the other child's state.

#+begin_src nim
import nest

type
  SearchEvent = enum
    QueryChanged
    QueryCleared

  ResultsEvent = enum
    ResultChosen

  Browser = object
    query: LineInputState
    results: seq[string]
    chosen: string

widget searchBox(state: LineInputState) emits SearchEvent:
  ui.row(ui.id("root"), cfg(width = fill(), height = fit(), gap = 6)):
    ui.lineInput(ui.id("input"), state, width = fill(), height = fixed(30))
    if ui.submitted(ui.id("input")):
      emit QueryChanged
    if ui.button(ui.id("clear"), "Clear", width = fit(), height = fit()):
      emit QueryCleared

widget resultList(items: seq[string]) emits ResultsEvent:
  ui.column(ui.id("root"), cfg(width = fill(), height = fit(), gap = 2)):
    for index, item in items:
      ui.scope(index):
        if ui.button(ui.id("item"), item, width = fill(), height = fit()):
          emit ResultChosen

widget browser(model: var Browser):
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 8,
      padding = 8)):
    for event in ui.searchBox(model.query):
      case event
      of QueryChanged:
        model.results = @["match for " & model.query.text]
      of QueryCleared:
        model.query.text = ""
        model.results.setLen(0)

    for event in ui.resultList(model.results):
      case event
      of ResultChosen:
        model.chosen = "chosen"

    ui.label(ui.id("chosen"), model.chosen, width = fill(), height = fit())
#+end_src

** Container Widgets

A parameter of type ~untyped~ takes a block, so a widget can wrap children the
caller supplies. A widget with such a parameter expands to a template.

#+begin_src nim
import nest

widget titledCard(title: string, body: untyped):
  ui.card(ui.id("root"), cfg(width = fill(), height = fit(), padding = 10,
      gap = 6)):
    ui.label(ui.id("title"), title, width = fill(), height = fit())
    body

widget settingsPage():
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 8,
      padding = 8)):
    ui.titledCard("General"):
      ui.label(ui.id("general"), "General settings", width = fill(),
          height = fit())
    ui.scope("advanced"):
      ui.titledCard("Advanced"):
        ui.label(ui.id("advanced"), "Advanced settings", width = fill(),
            height = fit())
#+end_src

A container's children are declared by the caller, so their events belong to the
caller too: they are collected in the caller's scope, not the container's.

import nest

type
  Counter = object
    count: int

  CounterEvent = enum
    Bumped

widget counter(model: Counter) emits CounterEvent:
  ui.row(ui.id("root"), cfg(width = fit(), height = fit(), gap = 6)):
    ui.label(ui.id("count"), $model.count, width = fixed(40), height = fit())
    if ui.button(ui.id("inc"), "+", width = fixed(30), height = fit()):
      emit Bumped

widget titledCard(title: string, body: untyped):
  ui.card(ui.id("root"), cfg(width = fill(), height = fit(), padding = 10)):
    ui.label(ui.id("title"), title, width = fill(), height = fit())
    body

widget page(model: var Counter):
  ui.column(ui.id("root"), cfg(width = fill(), height = fit(), gap = 8)):
    var emitted: seq[CounterEvent]

** Containers That Emit

A container expands to a template, so it cannot use ~emits~. Give it an
~emitted: var seq[E]~ parameter and append to that; the caller passes a sequence
it owns, which also means nothing is lost across the two passes.

#+begin_src nim
import nest

type
  PanelEvent = enum
    CloseRequested
    Collapsed

widget closablePanel(title: string, emitted: var seq[PanelEvent],
    body: untyped):
  ui.card(ui.id("root"), cfg(width = fill(), height = fit(), padding = 8,
      gap = 6)):
    ui.row(ui.id("head"), cfg(width = fill(), height = fit(), gap = 6,
        alignItems = AlignCenter)):
      ui.label(ui.id("title"), title, width = fill(), height = fit())
      if ui.button(ui.id("collapse"), "-", width = fixed(24), height = fit()):
        emitted.add Collapsed
      if ui.button(ui.id("close"), "x", width = fixed(24), height = fit()):
        emitted.add CloseRequested
    body

widget workspace(open: var bool):
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 8,
      padding = 8)):
    if open:
      var emitted: seq[PanelEvent]
      ui.closablePanel("Inspector", emitted):
        ui.label(ui.id("body"), "Panel contents", width = fill(),
            height = fit())
      for event in emitted:
        case event
        of CloseRequested: open = false
        of Collapsed: discard
#+end_src

** A Container That Reacts To Its Children

A container can both host arbitrary children and report its own events. The tab
strip below owns which tab is selected; the caller supplies the content.

#+begin_src nim
import nest

type
  TabsEvent = object
    selected: int

widget tabStrip(labels: openArray[string], current: int,
    emitted: var seq[TabsEvent], body: untyped):
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 6)):
    var picked = current
    ui.tabs(ui.id("tabs"), labels, picked, width = fill(), height = fit())
    if picked != current:
      emitted.add TabsEvent(selected: picked)
    ui.panel(ui.id("content"), cfg(width = fill(), height = fill(),
        padding = 8)):
      body

widget shell(tab: var int):
  const Labels = ["Files", "Editor", "Settings"]
  var emitted: seq[TabsEvent]
  ui.tabStrip(Labels, tab, emitted):
    case tab
    of 0: ui.label(ui.id("files"), "Files", width = fill(), height = fit())
    of 1: ui.label(ui.id("editor"), "Editor", width = fill(), height = fit())
    else: ui.label(ui.id("settings"), "Settings", width = fill(),
        height = fit())
  for event in emitted:
    tab = event.selected
#+end_src

** Batching

Because a widget returns every event of the frame, a parent can look at them
together before deciding anything.

#+begin_src nim
import nest

type
  CellEvent = object
    row, column: int

  Grid = object
    selection: seq[CellEvent]

widget cell(atRow, atColumn: int) emits CellEvent:
  if ui.button(ui.id("button"), $atRow & "," & $atColumn, width = fixed(48),
      height = fixed(24)):
    emit CellEvent(row: atRow, column: atColumn)

widget grid(model: var Grid):
  ui.column(ui.id("root"), cfg(width = fit(), height = fit(), gap = 2)):
    var clicks: seq[CellEvent]
    # Named `rowIndex`, not `row`: a local called `row` would shadow `ui.row`.
    for rowIndex in 0 ..< 3:
      ui.row(ui.id("row", rowIndex), cfg(width = fit(), height = fit(),
          gap = 2)):
        for columnIndex in 0 ..< 3:
          ui.scope(rowIndex * 3 + columnIndex):
            clicks.add ui.cell(rowIndex, columnIndex)

    # One frame can carry several clicks; decide once, with all of them in hand.
    if clicks.len > 1:
      model.selection = clicks
    elif clicks.len == 1:
      model.selection = @[clicks[0]]
#+end_src

* State

Each widget owns the state it needs, and a parent holds its children's state as
fields. There is no single application model: the root's state is whatever the
composition adds up to.

#+begin_src nim
import nest

type
  # Each widget's own state and events.
  Counter = object
    count: int

  CounterEvent = enum
    Bumped

  Notes = object
    text: EditorState

  NotesEvent = enum
    Saved

  # The parent holds its children's state, plus what belongs to it alone.
  Workspace = object
    counter: Counter
    notes: Notes
    status: string

  WorkspaceEvent = enum
    StatusChanged

proc update(model: var Counter, event: CounterEvent) =
  case event
  of Bumped: inc model.count

proc update(model: var Notes, event: NotesEvent) =
  case event
  of Saved: discard

widget counter(model: Counter) emits CounterEvent:
  ui.row(ui.id("root"), cfg(width = fit(), height = fit(), gap = 6)):
    ui.label(ui.id("count"), $model.count, width = fixed(40), height = fit())
    if ui.button(ui.id("inc"), "+", width = fixed(30), height = fit()):
      emit Bumped

widget notes(model: Notes) emits NotesEvent:
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 6)):
    ui.textEditor(ui.id("text"), model.text, width = fill(), height = fill())
    if ui.button(ui.id("save"), "Save", width = fit(), height = fit()):
      emit Saved

widget workspace(model: var Workspace) emits WorkspaceEvent:
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 8,
      padding = 8)):
    for event in ui.counter(model.counter):
      # Each child's state is updated by that child's own `update`.
      model.counter.update(event)
      model.status = "count " & $model.counter.count
      emit StatusChanged

    for event in ui.notes(model.notes):
      model.notes.update(event)
      model.status = "saved"
      emit StatusChanged

    ui.label(ui.id("status"), model.status, width = fill(), height = fit())
#+end_src

Two rules keep this straight as the tree grows:

- A widget reads its own state and its children's; it writes only through the
  ~update~ of whichever state it owns.
- A widget never reaches into a sibling's state. Its parent is where two
  children meet.

** Read-Only Children

A widget that only draws takes its state by value, which says in the signature
that it changes nothing.

        height = fixed(18))

** State That Outlives A Frame

~LineInputState~, ~EditorState~ and ~Mesh2DState~ hold text, cursors, selection
and scroll positions. They belong to the widget's own state and are mutated in
place by the widget that draws them; they are not carried in events.

#+begin_src nim
import nest
import std/sets

type
  Source = object
    path: string
    text: EditorState
    breakpoints: HashSet[int]

  SourceEvent = enum
    SaveRequested

widget sourceEditor(model: Source) emits SourceEvent:

* Layout

A container takes a ~BoxConfig~ from ~cfg~ and a body of declarations.
Constraint details are in [[file:layout.org][layout.org]].

* Custom Components

~widget~ composes existing widgets. A component is the other extension point: a
~Component~ subclass that measures, updates and draws itself, attached to a
widget with ~ui.component~. Write one when nothing built in draws what is needed.

| Method        | Called                          | Purpose                         |
|---------------+---------------------------------+---------------------------------|
| ~measure~     | before solving, for ~fit~ boxes | report the content's size       |
| ~update~      | once per frame, after solving   | react to input                  |
| ~draw~        | when the widget is dirty        | paint inside the widget's frame |
| ~drawOverlay~ | after every ~draw~              | paint above sibling widgets     |

A component that only draws:

#+begin_src nim
import nest
import nest/[coords, resources]

type ProgressBar = ref object of Component
  fraction: float64

proc new(T: typedesc[ProgressBar], fraction: float64): T =
  T(fraction: fraction.clamp(0.0, 1.0))

method measure(self: ProgressBar, resources: Resources): IntrinsicSize =
  intrinsicSize(120, 10)

method draw(self: ProgressBar, widget: Widget, ctx: var DrawContext) =
  let
    f = widget.frame
    track = rect(f.x.toInt, f.y.toInt, f.width.toInt, f.height.toInt)
    filled = rect(f.x.toInt, f.y.toInt, (f.width * self.fraction).toInt,
        f.height.toInt)
  fillRect(track, ctx.palette.panelMuted)
  fillRect(filled, ctx.palette.primary)
  lineRect(track, ctx.palette.panelBorder)

widget progressBar(fraction: float64, width = fill(), height = fixed(10)):
  discard ui.component(ui.id("bar"), ProgressBar.new(fraction), width, height,
      renderKeyOverride = "progress:" & $fraction)

widget download(progress: float64):
  ui.column(ui.id("root"), cfg(padding = 12, gap = 8)):
    ui.label(ui.id("label"), "Downloading", width = fit(), height = fit())
    ui.progressBar(progress)
#+end_src

~renderKeyOverride~ tells Nest when the widget must be repainted. A component
whose appearance depends on more than its size and alignment has to supply one,
or a changed value will not be drawn.

A component that reacts to the pointer derives from ~Interactive~, which also
marks its frame as blocking pointer input. Wrapping it in a ~widget~ that emits
gives it the same shape as any other widget in the tree.

#+begin_src nim
import nest
import nest/[coords, resources]

type
  Swatch = ref object of Interactive
    value: Color

  SwatchEvent = object
    value: Color

proc new(T: typedesc[Swatch], value: Color): T =
  T(value: value)

method measure(self: Swatch, resources: Resources): IntrinsicSize =
  intrinsicSize(24, 24)

method update(self: Swatch, widget: Widget, ctx: var UpdateContext) =
  let f = widget.frame
  let inside =
    ctx.mouseX.toFloat >= f.x and ctx.mouseX.toFloat < f.x + f.width and
    ctx.mouseY.toFloat >= f.y and ctx.mouseY.toFloat < f.y + f.height
  if inside:
    ctx.setHot(widget.id)
    if ctx.mouseLeftPressed:
      ctx.setActive(widget.id)

method draw(self: Swatch, widget: Widget, ctx: var DrawContext) =
  let
    f = widget.frame
    box = rect(f.x.toInt, f.y.toInt, f.width.toInt, f.height.toInt)
  fillRect(box, self.value)
  lineRect(box, if ctx.hot(widget.id): ctx.palette.primary
    else: ctx.palette.panelBorder)

widget swatch(value: Color) emits SwatchEvent:
  discard ui.component(ui.id("swatch"), Swatch.new(value), fixed(24), fixed(24),
      renderKeyOverride = "swatch:" & $value)
  if ui.clicked(ui.id("swatch")):
    emit SwatchEvent(value: value)

widget palette(colors: seq[Color], chosen: var Color):
  ui.row(ui.id("root"), cfg(width = fit(), height = fit(), gap = 4)):
    for index, value in colors:
      ui.scope(index):
        for event in ui.swatch(value):
          chosen = event.value
#+end_src

** Animation

A component asks for the next frame from its ~draw~ method.

import nest/[coords, resources]

type Spinner = ref object of Component
  discard

  T()

  intrinsicSize(16, 16)

  let

    size = (f.width / 2).toInt

  ctx.requestRedrawAfter(120)

* Growing The Application

Each stage below is reached only when the previous one becomes awkward. Nothing
about the architecture changes: a widget is added, it owns its state, and it
emits what its parent needs to know.

** Stage 1: One Widget

State, events, ~update~, widget, ~runApp~. This is the counter, and it stays
readable while the window has a handful of children.

** Stage 2: Children Without State

Split by region as soon as one widget declares more than a screenful. A region
that owns nothing takes what it draws and emits what it collects.

* Redraws

Frames are event driven. Without input, nothing is drawn. Four calls change
that.

| Call                        | Effect                                     |
|-----------------------------+--------------------------------------------|
| ~ui.requestRedrawAfter(ms)~ | schedule a frame; the soonest request wins |
| ~ui.markDirty(id)~          | repaint one widget on the next frame       |
| ~ui.markAllDirty()~         | repaint the whole frame                    |
| ~ui.markRealtime(id)~       | repaint this widget every frame            |

~runApp~ marks the frame dirty whenever an event was applied, so a widget only
asks for redraws that input does not already cause.

#+begin_src nim
import nest

type
  Clock = object
    seconds: int

  ClockEvent = enum
    Ticked

proc update(model: var Clock, event: ClockEvent) =
  case event
  of Ticked: inc model.seconds

widget clock(model: Clock) emits ClockEvent:
  ui.column(ui.id("root"), cfg(padding = 12, gap = 6)):
    ui.label(ui.id("uptime"), "uptime " & $model.seconds & "s", width = fit(),
        height = fit())
    ui.events:
      emit Ticked
    # One frame per second is enough for this label.
    ui.requestRedrawAfter(1000)
#+end_src

* Dialogs And Overlays

** Modal Dialogs

A dialog is a widget like any other, gated on a flag and declared outside the
root container so it is laid out over the whole frame.

#+begin_src nim
import nest

type
  ConfirmEvent = enum
    Confirmed
    Cancelled

  App = object
    confirmOpen: bool
    deleted: bool

  AppEvent = enum
    DeleteRequested
    DeleteDone
    DeleteCancelled

proc update(model: var App, event: AppEvent) =
  case event
  of DeleteRequested: model.confirmOpen = true
  of DeleteDone:
    model.confirmOpen = false
    model.deleted = true
  of DeleteCancelled: model.confirmOpen = false

widget confirmDialog(open: bool) emits ConfirmEvent:
  ui.modalDialog(ui.id("root"), open, cfg(width = fixed(320), height = fit(),
      padding = 12, gap = 10)):
    ui.label(ui.id("text"), "Delete the file?", width = fill(), height = fit())
    ui.row(ui.id("actions"), cfg(width = fill(), height = fit(), gap = 8,
        justifyContent = JustifyEnd)):
      if ui.button(ui.id("cancel"), "Cancel", width = fit(), height = fit()):
        emit Cancelled
      if ui.button(ui.id("ok"), "Delete", width = fit(), height = fit()):
        emit Confirmed

widget root(model: App) emits AppEvent:
  ui.column(ui.id("root"), cfg(padding = 12, gap = 8)):
    if ui.button(ui.id("delete"), "Delete", width = fit(), height = fit()):
      emit DeleteRequested
    ui.label(ui.id("state"), if model.deleted: "deleted" else: "not deleted",
        width = fit(), height = fit())

  for event in ui.confirmDialog(model.confirmOpen):
    case event
    of Confirmed: emit DeleteDone
    of Cancelled: emit DeleteCancelled
#+end_src

** Menus

A menu is an entry in a ~menuBar~ plus a floating card anchored under it. Both
ids belong to the same widget, which is why they are declared together.

#+begin_src nim
import nest

type
  MenuEvent = object
    command: string
    toggled: bool

widget fileMenu(open: bool) emits MenuEvent:
  ui.menuBar(ui.id("bar"), cfg(width = fill(), height = fit(), gap = 4)):
    if ui.menu(ui.id("file"), "File", width = fit(), height = fit()):
      emit MenuEvent(toggled: true)

  if open:
    ui.floatingCardBelow(ui.id("popover"), ui.id("file"),
        cfg(width = fixed(180), height = fit(), padding = 4, gap = 2)):
      for item in ["New", "Open"]:
        ui.menuItem(ui.id("item", item), cfg(width = fill(), height = fit())):
          ui.label(ui.id("itemText", item), item, width = fit(), height = fit())
        if ui.clicked(ui.id("item", item)):
          emit MenuEvent(command: item)
      ui.menuDivider(ui.id("divider"), width = fill(), height = fixed(9))
      ui.menuItem(ui.id("quit"), cfg(width = fill(), height = fit())):
        ui.label(ui.id("quitText"), "Quit", width = fit(), height = fit())
      if ui.clicked(ui.id("quit")):
        emit MenuEvent(command: "Quit")

widget shell(menuOpen: var bool, lastCommand: var string):
  ui.column(ui.id("root"), cfg(width = fill(), height = fill(), gap = 6)):
    for event in ui.fileMenu(menuOpen):
      if event.toggled:
        menuOpen = not menuOpen
      elif event.command.len > 0:
        lastCommand = event.command
        menuOpen = false
    ui.label(ui.id("last"), "last: " & lastCommand, width = fill(),
        height = fit())
#+end_src

** File Pickers

Pickers are provided by the host through ~ui.io~, and are asynchronous: start
one, then read its result on a later frame.

#+begin_src nim
import nest

type PickerEvent = object
  path: string

widget filePicker(current: string) emits PickerEvent:
  ui.row(ui.id("root"), cfg(width = fit(), height = fit(), gap = 8)):
    if ui.button(ui.id("browse"), "Browse", width = fit(), height = fit()):
      ui.io.files.pick(ui.id("browse"))

    ui.events:
      let picked = ui.io.files.value(ui.id("browse"))
      if picked.len > 0:
        ui.io.files.clear(ui.id("browse"))
        emit PickerEvent(path: picked)

    ui.label(ui.id("path"), current, width = fill(), height = fit())
#+end_src

* Testing A Widget

A widget can be driven without a window: replace the font relays with stubs,
build frames by hand, and assert on the events it emitted and the text it drew.
Entering the widget's scope gives a test the ids it declared.

#+begin_src nim
import std/strutils

import nest
import nest/screen

type
  Counter = object
    count: int

  CounterEvent = enum
    Bumped

proc update(model: var Counter, event: CounterEvent) =
  case event
  of Bumped: inc model.count

widget counter(model: Counter) emits CounterEvent:
  ui.row(ui.id("root"), cfg(padding = 8, gap = 8)):
    ui.label(ui.id("count"), $model.count, width = fixed(60),
        height = fixed(24))
    if ui.button(ui.id("inc"), "+", width = fixed(40), height = fixed(24)):
      emit Bumped

when isMainModule:
  var drawn: seq[string]

  fontRelays = FontRelays(
    openFont: proc(path: string, size: int, metrics: var FontMetrics): Font =
      metrics = FontMetrics(ascent: 14, descent: 4, lineHeight: 22)
      Font(size),
    closeFont: proc(f: Font) = discard,
    getFontMetrics: proc(f: Font): FontMetrics =
      FontMetrics(ascent: 14, descent: 4, lineHeight: 22),
    measureText: proc(f: Font, text: string): TextExtent =
      TextExtent(w: max(text.len, 1) * 9, h: 18),
    drawText: proc(f: Font, x, y: int, text: string, fg, bg: Color): TextExtent =
      drawn.add text
      TextExtent(w: max(text.len, 1) * 9, h: 18),
  )

  var
    ui = UI.init()
    model = Counter()
    emitted: seq[CounterEvent]

  ui.initContext(320, 200)
  ui.loadFont("font", "", 18)

  proc frame() =
    drawn.setLen(0)
    ui.markAllDirty()
    ui.layout:
      ui.events:
        emitted.setLen(0)
      # Accumulated, never assigned: the layout pass emits nothing.
      emitted.add ui.counter(model)
      ui.events:
        for event in emitted:
          model.update(event)
    ui.finishInputFrame()

  # First frame: the initial state is drawn, nothing is emitted.
  ui.beginInputFrame()
  frame()
  doAssert "0" in drawn
  doAssert emitted.len == 0

  # The button's id belongs to the widget, so the lookup enters its scope.
  var plusID: WidgetID
  ui.scope("counter"):
    plusID = ui.id("inc")
  let plus = ui.widgetFrame(plusID)
  doAssert plus.ok

  # Press the button. The press is recorded this frame.
  ui.beginInputFrame()
  ui.mouseMove((plus.frame.x + plus.frame.width / 2).int,
      (plus.frame.y + plus.frame.height / 2).int)
  ui.mouseDown()
  frame()

  # Next frame: the click is observed, emitted, applied, and drawn.
  ui.beginInputFrame()
  frame()
  doAssert emitted == @[Bumped]
  doAssert model.count == 1
  doAssert "1" in drawn

  echo "widget test passed"
#+end_src

* Conventions

- Declare every portion of the interface with ~widget~.
- Give a widget its own event type with ~emits~, named after what happened, not
  after what the parent should do about it.
- Handle a child's event, or emit one of your own in its place. Never reach past
  a parent to a grandchild's state.
- A widget owns its state; a parent holds its children's state as fields and
  calls their ~update~.
- Consume events where they are returned, or accumulate them with ~add~. Never
  assign them to something that outlives the call.
- Collect a list's events first, edit the list afterwards.
- Mutate nothing outside ~ui.events~.
- Wrap a repeated widget in ~ui.scope~ at the call site.
- Build ids from data, not from a loop index.
- A container takes a ~body: untyped~ parameter, which makes it a template: it
  cannot use ~emits~, so give it ~emitted: var seq[E]~, and avoid parameter names
  that also appear as field names in its body.
- Keep ~LineInputState~, ~EditorState~ and ~Mesh2DState~ in the widget's state.
- Reach for a ~Component~ subclass only when nothing built in draws what is
  needed, and give it a ~renderKeyOverride~ when its appearance depends on more
  than its size.
- ~import nest~ covers the widget API; ~rect~ and ~point~ come from
  ~nest/coords~, and ~Resources~ from ~nest/resources~.
